# Kick Chat Component

A composable chat container built for Kick's streaming platform. The component uses a dark neutral theme with Kick's signature green accent colors.

## Brand-Specific Shadow

Kick's chat has a distinctive green glow:

```
shadow-chat: 0 0 60px rgba(83, 252, 24, 0.15), 0 25px 50px -12px rgba(0, 0, 0, 0.5)
```

## Usage

```tsx
import { Chat } from "@easygo-ds-kick-chat";
import { Button } from "@easygo-ds-kick-button";

<Chat>
  <Chat.Header>
    <span className="h-2 w-2 rounded-full bg-button-primary" />
    <span>Live Chat</span>
  </Chat.Header>
  <Chat.Body>
    {messages.map((msg) => (
      <div className="bg-chat-message rounded-lg px-3 py-2">
        <span className="text-button-primary">{msg.username}</span>
        <p>{msg.message}</p>
      </div>
    ))}
  </Chat.Body>
  <Chat.Footer>
    <input className="bg-chat-input" placeholder="Send a message..." />
    <Button size="sm">Chat</Button>
  </Chat.Footer>
</Chat>;
```
