# Stake Chat Component

A composable chat container built for Stake's support and concierge features. The component uses a dark slate theme with Stake's blue accent colors.

## Brand-Specific Shadow

Stake's chat has a subtle blue glow:

```
shadow-chat: 0 0 60px rgba(20, 117, 225, 0.1), 0 25px 50px -12px rgba(0, 0, 0, 0.4)
```

## Usage

```svelte
<script>
  import { Chat, ChatHeader, ChatBody, ChatFooter } from "@easygo-ds-stake-chat";
  import { Button } from "@easygo-ds-stake-button";
</script>

<Chat>
  <ChatHeader>
    <select class="bg-chat-input">
      <option>🇺🇸 English</option>
      <option>🇪🇸 Spanish</option>
    </select>
  </ChatHeader>
  <ChatBody>
    {#each messages as msg}
      <div class="bg-chat-message rounded-lg px-3 py-2">
        <span class="text-button-primary">{msg.username}</span>
        <p>{msg.message}</p>
      </div>
    {/each}
  </ChatBody>
  <ChatFooter>
    <input class="bg-chat-input" placeholder="Send a message..." />
    <Button size="sm">Send</Button>
  </ChatFooter>
</Chat>
```
